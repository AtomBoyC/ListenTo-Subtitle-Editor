## 已确认的问题与处理

### 1. 完整的日译英模型被误判为损坏

- **现象**：下载完成后出现“翻译模型不完整或语言代码不符”，无法准备日语 → 英语模型。
- **原因**：官方 Argos 日译英 1.1 使用旧版 CTranslate2 布局，包含 TXT 词表而没有 `model/config.json`；旧校验逻辑错误地把该文件当作所有版本的必需文件。
- **处理**：兼容旧版 TXT 与新版 JSON 词表布局，继续校验模型、语言元数据和分词器；保留下载与解包校验。
- **状态**：已修复，见 [feb6c34](https://github.com/AtomBoyC/ListenTo-Subtitle-Editor/commit/feb6c34)。

### 2. 目标选中文，却显示或下载日译英

这里有两个不同情况：

- **正常的中转路线**：当前离线日译中使用 **日语 → 英语 → 中文**。下载日译英模型是第一步，并不表示最终目标变成英语。启动日志现已显示完整路线和最终目标。
- **已复现的界面问题**：Windows Tk 的只读下拉框会响应鼠标滚轮，选项可能在滚动页面时意外从中文变成英语。这是可能造成选项误切换的程序问题，不能仅凭截图断定当次操作经过。

**处理**：阻止下拉框上的滚轮误切换；任务开始时固定所选参数，运行中禁用相关控件，失败后保留语言选择。已修复，见 [feb6c34](https://github.com/AtomBoyC/ListenTo-Subtitle-Editor/commit/feb6c34)。

### 3. 第 54 条短句返回空译文，整项任务中断

- **现象**：一份 513 条的日语 SRT，在完成前 53 条后报“第 54 条字幕未得到译文”。
- **原因**：该条包含正常日语文字；模型排序第一的候选只有分词空白标记，解码后为空，而后续候选存在有效译文。旧逻辑只取一个候选，并将空译文视为整个任务失败。
- **处理**：仅在首选无效时尝试最多 4 个候选；仍无有效候选则保留该片段最初的原文，跳过其后续中转，并明确警告。第二步英译中失败时，也恢复最初日文，避免把英语中间结果当作中文。
- **状态**：已修复处理逻辑，第 54 条已在实际离线复测中译出。见 [e2cb675](https://github.com/AtomBoyC/ListenTo-Subtitle-Editor/commit/e2cb6752e6f2fd4052f381227f30a18ebb1e2385)。

### 4. 译文夹带 ASS 控制标签、纯假名或私用区字符

- **现象**：实际复测中，模型给普通字幕额外生成了 ASS 样式标记；另有候选只剩日语假名，或包含 Unicode 私用区字符。
- **原因边界**：这些输出已观察到，但尚无证据证明具体训练样本污染或 CPU/int8 导致它们。当前推理允许未知词复制，这是部分原文残留的可能因素，尚未逐词验证。
- **处理**：只清理模型新增、格式完整的 ASS 控制块，并记录警告；对非日语目标拒绝仅含假名的文字候选，拒绝生成的私用区字符，然后尝试其他候选或保留最初原文。原字幕受保护的样式继续保留。
- **限制**：这属于有限的无效输出检测。共享汉字、混合人名及语义错误仍可能通过，不能据此保证译文正确。
- **状态**：已加入处理，见 [e2cb675](https://github.com/AtomBoyC/ListenTo-Subtitle-Editor/commit/e2cb6752e6f2fd4052f381227f30a18ebb1e2385)。

### 5. 未完成的片段需要准确标记

**处理**：日志指出原字幕条目，并汇总未完成数量；界面显示“部分片段未翻译，已保留原文”。双语输出避免把回退原文重复写两遍，保留原时间轴与顺序。已修复，见 [e2cb675](https://github.com/AtomBoyC/ListenTo-Subtitle-Editor/commit/e2cb6752e6f2fd4052f381227f30a18ebb1e2385)。

- 在禁止网络请求的条件下，完成 513 条 SRT 的实际离线日译中处理；源文件、字幕编号、顺序与时间轴保持不变，导出无空条目、无模型新增的 ASS 控制标记。
- 第 54 条恢复成功；两处模型生成的样式标记被清理并报告。
- **仍有 3 条未完成目标翻译（331、401、454）**，已保留最初日文并明确报告。因此，这是完整处理并输出部分翻译结果，不是全部条目翻译成功，也不是人工质量验收。

## 离线模型现状与更新需求

截至本次官方索引核查：

| 方向 | 本机已安装版本 | 官方索引可用版本 |
| --- | --- | --- |
| 日语 → 英语 | 1.1 | 1.1 |
| 英语 → 中文 | 1.9 | 1.9 |
| 日语 → 中文 | 无直接模型 | 无直接模型 |

目前两段中转模型已是索引中可用的版本。重复下载同版本不会更新模型权重；升级推理库也不等于换成更好的翻译模型，无法保证翻译质量提高。

程序会优先使用完整的本地路线，并选择同方向已安装的最高版本；本地路线完整时不会访问官方索引。**目前没有手动“检查模型更新”或模型管理界面**。
