# 听见 Studio 2.0 · 全平台部署与使用指南

本文档涵盖 **Windows / macOS 桌面应用（双击即用）**、**Linux 云服务器 / NAS Docker Compose 部署** 以及 **源码开发与自行打包** 的完整操作说明。

---

## 一、Windows 与 macOS 桌面版（直接打开即用）

如果你不想折腾命令行或 Python 环境，直接前往本仓库的 **[GitHub Releases 页面](https://github.com/AtomBoyC/ListenTo-Subtitle-Editor/releases/latest)** 下载对应系统的安装包即可。

### 1. Windows 10 / 11 (64 位)

1. 下载 **`ListenTo-Studio.exe`**（或压缩包 `ListenTo-Studio-Windows-x64.zip` 解压得到 `.exe`）。
2. **双击 `ListenTo-Studio.exe`** 即可直接启动独立桌面窗口（基于 Windows 10/11 系统自带的 Microsoft Edge WebView2 渲染引擎，无需安装浏览器或 Python）。
   - *注：若首次双击弹出 Windows SmartScreen 蓝色提示框，点击「更多信息」→「仍要运行」即可。*
3. **文件存储位置**：
   - **API 密钥与项目自动存档**：`%APPDATA%\ListenToStudio\`（关闭或更新 `.exe` 不会丢失配置）
   - **默认字幕导出目录**：`%USERPROFILE%\Downloads\ListenTo-Subtitles\`（导出完成后可在弹窗内一键点击「📂 打开导出文件夹」）

### 2. macOS（支持 Apple Silicon M1–M4 与 Intel 芯片）

1. 根据你的 Mac 芯片类型下载安装包：
   - Apple Silicon（M1 / M2 / M3 / M4）：下载 **`ListenTo-Studio-macOS-arm64.dmg`**
   - Intel 芯片 Mac：下载 **`ListenTo-Studio-macOS-x64.dmg`**
2. 双击打开 `.dmg`，将 **`ListenTo Studio.app`** 拖入右侧 **`Applications`（应用程序）** 文件夹。
3. **首次打开未公证应用放行说明**：
   - 由于开源免费项目未使用付费 Apple Developer ID 公证，首次双击若提示「无法打开或无法验证开发者」，可执行以下任一操作放行（仅首次需要）：
   - **图形界面操作**：打开「系统设置 → 隐私与安全性」，拉到底部点击 **「仍要打开」**；
   - **终端一行命令放行**：
     ```bash
     xattr -cr "/Applications/ListenTo Studio.app"
     ```
4. **文件存储位置**：
   - **API 密钥与项目自动存档**：`~/Library/Application Support/ListenToStudio/`
   - **默认字幕导出目录**：`~/Downloads/ListenTo-Subtitles/`

## 二、云服务器 / NAS Docker Compose 生产部署

镜像已发布至 Docker Hub（`atomboyc/listento-subtitle-editor:latest`）与 GHCR（`ghcr.io/atomboyc/listento-subtitle-editor:latest`），原生支持 **`linux/amd64`** 与 **`linux/arm64`** 双架构。

### 1. 服务器极速单文件部署（无需克隆代码仓库）

在任意安装了 Docker 与 Docker Compose 的 Linux 服务器上执行：

```bash
mkdir -p listento-studio && cd listento-studio
curl -fsSL https://raw.githubusercontent.com/AtomBoyC/ListenTo-Subtitle-Editor/master/docker-compose.yml -o docker-compose.yml
docker compose up -d
```

启动后访问 `http://<你的服务器IP>:8765` 即可使用。

### 2. 1Panel / Portainer / 群晖 / 飞牛 OS 面板编排模板

在容器管理面板中新建 Compose 项目，直接粘贴以下内容：

```yaml
services:
  listento-studio:
    image: atomboyc/listento-subtitle-editor:latest
    container_name: listento-studio
    restart: unless-stopped
    ports:
      - "8765:8765"
    environment:
      - PORT=8765
      # 可选：预设默认 API Key，也可留空并在网页右上角「配置 API Key」中可视化填写保存
      - DEEPSEEK_API_KEY=
      - OPENAI_API_KEY=
      - GEMINI_API_KEY=
    volumes:
      - ./data:/data
      - ./exports:/exports
    extra_hosts:
      - "host.docker.internal:host-gateway"
```

### 3. Nginx 反向代理与 HTTPS 配置要点（支持 SSE 实时翻译进度流）

如果你通过域名 + Nginx 反向代理暴露服务，请务必为流式翻译接口关闭缓冲（`proxy_buffering off;`），确保网页端能逐批实时看到翻译进度条与审校笔记：

```nginx
server {
    listen 443 ssl http2;
    server_name sub.example.com;

    client_max_body_size 30M;

    location / {
        proxy_pass http://127.0.0.1:8765;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header Connection "";

        # 关键：关闭代理缓冲以保障 SSE 实时流式推送与长批次响应
        proxy_buffering off;
        proxy_cache off;
        proxy_read_timeout 300s;
    }
}
```

### 4. 升级镜像与数据备份

- **无缝升级到最新版**：
  ```bash
  docker compose pull && docker compose up -d
  ```
- **数据备份**：所有加密配置（`settings.json`）与自动保存的字幕工程均位于宿主机 `./data` 目录下，备份该目录即可完整迁移。

## 三、核心功能使用指引

1. **音视频 AI 语音识别转字幕 (`🎙️ 音视频转字幕`)**
   - 直接将没有字幕的 `.mp4 / .mov / .mkv / .mp3 / .wav / .m4a` 拖入欢迎页或点击顶部 **「🎙️ 音视频转字幕」**。
   - 内置 **硅基流动 SenseVoiceSmall（国内免费/极速首选）**、**Groq Whisper Large V3 Turbo（秒级原生时间轴）**、**OpenAI Audio** 及本地离线 **Faster-Whisper** 预设；识别完成后自动导入双语编辑台并将音视频挂载到左侧 16:9 监看台。
2. **配置并实时发现 AI 翻译模型 (`⚙️ AI 引擎设置`)**
   - 内置 **13 家主流平台最新旗舰模型预设**（DeepSeek V4、OpenAI GPT-6.2/GPT-5、Google Gemini 3.8/3.5、Claude 5.5、通义千问 Qwen4-Max、火山方舟豆包、Kimi K3.1、智谱 GLM-5.1、xAI Grok 4.7、硅基流动、OpenRouter、本地 Ollama/LM Studio 及自定义中转站）。
   - 点击 **「🔄 实时拉取可用模型」** 可直接读取你当前 API 账号下支持的全部实时模型并按关键词过滤点选。
3. **术语表锁定与上下文反思精翻**
   - 点击左侧 **「✨ AI 自动扫描全片提取人名/术语表」** 自动总结背景摘要并锁定专有名词译法；默认推荐 **「✨ 反思精翻（直译→审校→地道意译）」** 模式处理跨时间轴断句。
4. **双语精修、智能拆分与字幕质量体检 (`🩺 字幕体检`)**
   - 支持全键盘流操作（点击右上角 `⌨` 查看快捷键速查：`Tab` 跳行、`Alt + ↑/↓` 跳行定帧、`Alt + Enter` AI 单句重翻、`Cmd/Ctrl + S` 保存）。
   - 单条字幕过长时，点击行右侧 `⋯` → **「✂️ 智能拆分为两条字幕」** 自动按字符比例切分时间与文本。
   - 点击工具栏 **「🩺 字幕体检」** 可一键扫描时间轴重叠、行尾冗余标点、语速超标与漏译行，并点击 **「🔧 一键修复重叠与标点规范」** 自动修正。
5. **历史工程管理 (`🗂 历史工程`) 与影院级 ASS 无损导出**
   - 点击顶部 **「🗂 历史工程」** 可随时查看多集/多项目的翻译进度百分比并一键切换恢复。
   - 点击右上角 **「无损导出」**，内置 **经典高清描边、Netflix 沉浸暗盒、美剧经典暖黄、现代极客浅金** 4 款 ASS 双语视觉模板，并支持导出前点击 **「👁 刷新源码预览」** 实时检视生成内容。

## 四、开发者从源码运行或本地打包桌面端

### 1. 本机直接启动网页服务

- **macOS / Linux**：`./start.sh`
- **Windows**：双击 `Start.cmd`

### 2. 本机打包独立桌面端（`.app` / `.dmg` / `.exe`）

```bash
python3 -m venv .venv
# macOS / Linux:
./.venv/bin/pip install -r requirements-desktop.txt
./.venv/bin/python packaging/build_desktop.py

# Windows PowerShell:
.\.venv\Scripts\pip install -r requirements-desktop.txt
.\.venv\Scripts\python packaging\build_desktop.py
```

打包产物（含自动自检通过的 `.app` / `.dmg` / `.exe` / `.zip`）将输出在 `dist/` 目录下。
